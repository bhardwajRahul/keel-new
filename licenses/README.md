# retained third-party texts

The license and notice files in this directory are preserved verbatim from
the published Keel source. The macOS packager includes this entire directory
under `Keel.app/Contents/Resources/licenses/`.

See the [notice index](../THIRD_PARTY_NOTICES.md) for the components Keel uses
and [LICENSE](../LICENSE) for Keel's own license.

`THIRD_PARTY_NOTICES.deepseek-harness.md` is a retained upstream document.
Its npm/Python dependency lists, generator commands, and relative links describe
the upstream TypeScript repository, not Keel's Rust workspace. Keel's pinned
Rust dependency versions are recorded in the repository-root `Cargo.lock`.
