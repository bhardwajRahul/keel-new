# onboarding

[Documentation](README.md) / onboarding

## 1. enter the workspace

The ASCII app mark animates, then shows **Continue**. Returning users can also choose **Start a new session**. Reduced motion shows the completed mark immediately.

## 2. choose a decision mode

- **Local Laya:** saved default. The light package offers a model download with progress and verification.
- **Jev:** available when the existing protected TypeSafe credential is present.
- **Normal harness:** explicitly turns selector calls off.

Continuing while Laya downloads keeps the preference saved. The ordinary harness runs until the model is ready. The full package already contains the model.

![The three modes and their readiness requirements.](diagrams/decision-modes.svg)

## 3. discover coding tools

**Settings → Accounts** refreshes installed CLI status. Codex and Claude account status is shown only when confirmed locally; other tools report CLI-managed status.

**Settings → Agents** controls available adapters. Each provider retains its own authentication and model settings.

## 4. choose a model and work

The picker exposes reasoning, plan, and fast controls when the connected agent advertises them.

The chat names Laya or Jev only during an actual selector call. Pinned routes and existing sessions remain unchanged.

## reopen setup

Use **Settings → Onboarding** to revisit the choices and download progress. **Settings → Agents** also offers the model download.

See the [user guide](guide.md) for terminal commands, troubleshooting, computer use, and voice input.
